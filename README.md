# Readbox Sync / krsync

KOReader 阅读统计、进度、划线、批注与封面同步插件。可独立推送到两台兼容服务器，支持在线升级。针对 KOReader 2026.07.2 的 API 检查；实际 Kindle 安装仍需验证。

## 首次安装

从 Releases 下载 `krsync.koplugin.zip`，解压后将 `krsync.koplugin` 放到 KOReader 的 `plugins` 目录，重启 KOReader。

已有插件可只覆盖 `main.lua`。请保留 `settings/krsync.lua`，原网址、同步口令和设备名都在该文件中。

菜单：工具 → Readbox 同步 → 配置。前两栏仍是原服务器网址和同步口令；第三栏是设备名；后两栏是备用服务器网址和口令。网址填写服务器根地址，不要附加 `/api/push`。

两端顺序上传但独立计算结果。主端失败仍尝试备用，清空任意一端的网址可停用该端。服务器网址存在但口令为空时会明确提示失败。

## 封面

优先上传书籍 sidecar 目录的 `cover.jpg/png/webp` 等图片；没有独立图片时通过 KOReader 获取电子书内置封面，缩放后上传。每端每次最多 12 张，成功记录分端保存，失败留待重试。

1.1.0 首次运行会清理旧的封面成功记录以补传旧版本漏掉的图片；网址和口令保留。也可在菜单选择“重新补传封面”。查看同步结果可看到两端各自的成功、失败和待传数量。

封面缺失也可能发生在服务端：HTTP 200 应代表图片已正确关联书籍或已有可用封面，书籍不存在或数据库关联失败必须返回错误，便于插件重试。

## 在线升级

首次安装本版本仍需复制文件，旧版没有在线升级菜单。

之后连接 WiFi，在插件菜单点击“检查插件更新”，有新版本时确认安装，再重启 KOReader。更新前校验 SHA-256、文件长度、版本及 Lua 语法；保留 `main.lua.bak` 作为上一版备份。下载失败或校验失败不会覆盖当前插件。更新只替换 `main.lua`，不会修改同步配置。

更新信息来自本仓库 `main/ota.txt`，代码来自对应版本标签。升级适用于保持单文件布局的插件版本。其他资源或配置迁移需专门设计兼容升级。

## 后续发布

修改代码后运行 `node scripts/prepare-release.js 1.1.1`（填写新的三段版本号），运行测试，将代码与生成的 `ota.txt` 一起提交到 main。发布工作流通过测试后创建对应版本标签和安装 ZIP。已有标签不会自动覆盖；同一版本不应重复修改。

本地检查：`pnpm install --frozen-lockfile`，然后 `pnpm test`。

## 隐私

仓库仅包含通用插件代码和使用虚构数据的测试。不上传 Kindle 的 `settings/krsync.lua`、同步口令、真实服务器配置、阅读记录、笔记、日志或本地备份。服务端仍应验证同步口令，不能只依赖网址不公开。
